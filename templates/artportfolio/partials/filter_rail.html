{# The filter rail: a search field and a keyboard legend, and nothing else. Collections, tags and the visibility group belong to later slices. A full-screen "Filters" sheet holding one input would be an empty gesture, so below 900px this collapses to the search field alone (see style.css). The input carries its own HTMX attributes: HTMX includes a named input's own value, so no hx-include is needed. There is deliberately no hx-push-url — that pushes the REQUEST url, i.e. the fragment endpoint. The server sends an HX-Push-Url header naming the real page instead (see routes/feed.rs). #}
