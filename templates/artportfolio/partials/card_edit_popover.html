{# The caption/tags edit popover for one card, fetched via `GET /api/admin/posts/{id}/edit`. It exists as a GET-then-fill round trip rather than an always-empty inline form because a `Post` carries no tags — an empty tags input plus the PATCH's replace-all semantics would silently wipe a post's tags on the first Save a visitor didn't touch. Consumes `post_id: i64`, `caption: String`, `tags_joined: String` (comma-space joined) from scope. The Save button carries the hx-patch, matching the swap contract every visibility button in `post_card.html` already uses: `hx-target="closest .hm-post" hx-swap="outerHTML"` — htmx gathers the enclosing form's fields for a triggering element that is not itself the form. `onsubmit="return false"` — the tags input is the form's only field that doesn't block implicit submission, so Enter there would otherwise submit the bare form as a real GET to the current URL. Both shells set `hx-boost="true"` on ``, so that GET boosts: it swaps the whole page body and discards this popover along with whatever wasn't Saved yet. Same idiom `filter_rail.html`'s search form already uses. #}
