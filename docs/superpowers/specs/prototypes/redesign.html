WHAT CHANGED
  • Card + rule is now the hero on both surfaces; drink logging moved to a permanent thumb-zone bar so it never competes with the game.
  • Three tabs (Game / Standings / Room) replace one long scroll — nothing important is below the fold at 8 players.
  • Big screen is a real 50/50: card and rule at 62px on the left, live standings at 26px on the right, plus QR, King's Cup fill and house rules.
  • Held cards show the holder's name big on the screen; the USE button still only appears on the holder's phone.
  • Jacks now capture the rule they create, so "Make a Rule" persists into a list instead of being forgotten.
  • Logging a drink floats a beer or shot emote up from the button on both surfaces and fires a sound; the ♪ button in the room's top bar mutes it. Files go in sounds/ — see the README in there.
