Wires

Status: the ghost ladder

draft set · open issue 2

Like a Factorio ghost, an unbuilt machine is see-through: the grid shows through its body and its border is dashed. Its text stays readable; only the body fades. Building turns amber, the site’s “live” colour. Done is solid. Violet never means a status: it means selected.

A blueprint node

A group of machines collapsed into one node with its own ports. It is drawn as a stack, a node with a second one behind it, plus the layers mark and a footer naming the graph it opens into and how many machines that graph holds.

The stored format supports it from day one: the node’s graph key names an entry in the flat graphs map. Entering it is a later slice, so the footer’s open · later is visibly inert: dashed, muted, no hover.

If the named graph is missing, the footer says missing instead of a count.

Making a node: drag a wire into space

Releasing a wire over empty grid opens the search box where the wire ends. Typing names the new machine. Enter creates it with an input of the same type, already wired.

The box is drawn in screen space: it stays 300px wide at any zoom. Esc drops the wire and changes nothing, so there is nothing to undo.

From a keyboard: select a port, press W to start a wire, then A opens the same box.
