The numbers behind the canvas.

Built on the Hampter Design System as the site’s own screens wear it (site-dark). Everything below is a value blueprint-model.js can compute and a node test can pin.

The grid unit

  • 1u = 1rem, 16px at the browser default and 100% zoom. Every stored position is in whole units, which gives the factory snap. The README’s [4, 6] stays [4, 6] at any screen size.
  • Three line weights: every unit at 2.2% white, every 2u at 4.5% (the site’s own 32px texture), every 8u at 7.5%. The grid scales with zoom.
  • A node’s width and height round up to whole units, so its edges sit on lines.

Node geometry

{{g.k}} {{g.v}}
w = ceil(max(1.875u + 0.45u·longest_label, title_row, footer)), at least 9u h = ceil(3.125u + 1.5u·ports + notes + footer), in whole u on screen: px = u · rem · zoom

Sizes are stated in grid units, not pixels. 1u follows the root font size (1rem, 16px by browser default), and the canvas zoom multiplies everything at once. Fit (F) sets that zoom from the viewport, so a node scales with the screen. Its proportions never change.

Type

Archivo 800 · page headings Space Grotesk 400/500 · prose, controls, the inspector’s labels in sentences IBM Plex Mono 13/500 · node titles IBM Plex Mono 12 · ports, types, counts, outline.md IBM Plex Mono 11 · notes, readouts, 0.10em caps labels

Everything on the canvas is monospace, at 0.6em per character: 7.2px at 12px. That is what makes node size pure arithmetic and testable on plain node. Plex Mono is the face the site already self-hosts.

Wire curve rules

  • Cubic bezier, port to port, both tangents horizontal: a wire always leaves an output to the right and enters an input from the left.
  • Forward: control offset c = max(3u, dx/2). Backward (target left of source): c = max(6u, |dx|/2 + 3u), so it loops out of the node instead of cutting through it.
  • 2px at 100%, drawn under nodes, coloured by the type it carries. No reroute knots: they are layout-only clutter in the AI view.

Port colour from the type label

hue = 30 + fnv1a32(label) mod 300 colour = hsl(hue 70% 70%)

Hues 330° to 30° are never handed out: that rose band means mismatch. The label is hashed after the same folding the mismatch rule uses (open issue 6), so two labels that count as one type always share a colour. Shown here with case and spaces ignored.

Keyboard and mouse

{{k.what}} {{c.t}}

Undo keeps a snapshot per action, as the sorting board does; a whole drag is one entry. Keys in muted text are reserved: the site’s palette and search, and the later nesting slice. Right-click menus and the rest of the keyboard model are on the input model guide.

Motion and focus

Controls 130ms, panels 190ms, the search box 280ms, all cubic-bezier(.2,.8,.3,1), and none under prefers-reduced-motion. Pan and zoom never animate: the canvas follows the pointer exactly. Press is translateY(1px), never a scale. Nodes take the site’s double focus ring, 0 0 0 2px #0B0910, 0 0 0 4px #B48EF7.
