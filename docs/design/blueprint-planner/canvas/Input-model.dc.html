Right-click, keys and focus.

Everything a mouse can do, a keyboard can do too, and every right-click menu shows the key for each item. Keys from the shortcut table on the grid-and-geometry guide keep their meaning. Additions are marked new.

Right-click menus, one per target

Right-click with the mouse, long-press on touch, or focus the thing and press Shift + F10 (or the Menu key). Same menu every way. Up and down arrows move through the items, Enter runs one, and → opens a submenu.
